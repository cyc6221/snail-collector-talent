# 天賦資料

一個 CSV 對應一個分支，一列是一個節點：

| 檔案 | 分支 |
|---|---|
| `left.csv` | 左・資源 |
| `middle.csv` | 中・戰力 |
| `right.csv` | 右・兵種 |

## 更新流程

1. 用 Excel／Google 試算表編輯 CSV，存成 **CSV UTF-8（逗號分隔）**。
2. 執行 `node tools/build-data.mjs`，會產生網頁讀取的 `left.js`、`middle.js`、`right.js`。有格式問題時會指出檔名與列數，且不會更新任何 `.js`。
3. CSV 與 `.js` 一起提交。**不要直接改 `.js`**，下次轉換會被覆蓋。

## 欄位

| 欄位 | 說明 |
|---|---|
| 分支 | 分支名稱，同一檔案內必須一致 |
| 層 | 第幾層，從 1 連續編號；同一層的列（1～2 個節點）填同一個數字 |
| 層門檻 | 本層等級合計 ≥ 此值，下一層才解鎖；可留空（預設 5），同一層填一致即可 |
| 節點ID | 唯一識別碼（跨檔案也不可重複）：英文字母開頭，只能用英數、底線、連字號。使用者的配點以 id 記錄，**發佈後請勿更改** |
| 名稱 | 節點名稱 |
| 顏色 | 藍／紫／橙 |
| 每級消耗 | 整數 |
| 最高等級 | 整數，可留空（預設 5） |
| 效果 | `屬性 \| 每級數值 \| 單位`，多個效果用分號 `;` 隔開，例：`時光機探索產量 \| 5 \| %; 時光機容量 \| 5 \| %`。單位可留空，數值可為負 |
| 備註 | 顯示在卡片上的小標籤，可留空 |
| 點滿解鎖下一層 | 填「是」表示這個節點必須**點滿**，才能解鎖下一層；有節點標記「是」的那一層，只看這些節點，同層其他節點點多少都無關，「層門檻」也不再適用。留空＝一般規則（整層合計達門檻）。例：第 14 層橙色節點填「是」，紫色節點留空 |

> 使用者的瀏覽器只存配點與擁有點數，資料每次都直接讀取這些檔案，所以提交後所有人下次開啟就是最新版。配點以節點 ID 記錄，因此不要更改已發佈的 ID，否則該節點的配點會消失。

## 紅色天賦（`red.csv`，第 16 層）

不屬於任何分支，畫面上接在三個分支的最後一層之下，只有一個節點。格式與分支 CSV 不同，一列就是這個節點：

| 欄位 | 說明 |
|---|---|
| 節點ID | 規則同分支節點，三個分支與這裡之間也不可重複 |
| 名稱 | 節點名稱 |
| 顏色 | 填「紅」或留空 |
| 每級消耗 | 每升一級要花的各色點數，可以同時花多種，例：`藍 5; 紫 5; 橘 5` |
| 最高等級 | 整數，可留空（預設 5） |
| 效果 | 同分支 CSV：`屬性 | 每級數值 | 單位`，多個用分號隔開 |
| 解鎖來源節點 | 要看哪些分支節點的等級，填節點ID，多個用分號隔開，例：`res-15a; pow-15a; arm-15a` |
| 解鎖所需等級合計 | 上面那些節點的等級加起來要達到多少，才能點這個節點 |
| 備註 | 顯示在卡片上的小標籤，可留空 |

- 目前畫面只支援 **1 個**紅色天賦，轉換工具會檢查。
- 它的效果在「能力加總」裡**獨立一項**（紅色天賦），不與各分支相加。
- 它花的點數會計入頂部的已用點數。
- 降級會讓它失去解鎖時（例如把「解鎖來源節點」降到合計不足），必須先減少它自己的點數。
- 這份檔案是選用的：沒有 `red.csv` 時，網站照常運作，只是沒有第 16 層。
